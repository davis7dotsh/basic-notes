# Moonstone

Edit the folded swift and its glass materials in `App/Resources/Moonstone.icon` with Icon Composer. Xcode compiles the layered icon and its legacy macOS fallback during the app build.

Run `scripts/make-icon.sh` with Xcode 27 to refresh the README and Raycast PNGs. The menu bar uses the monochrome vector in `App/Resources/Assets.xcassets/StatusIcon.imageset`.
